# WhatsApp Sales Desk

A single-page, GitHub Pages-ready demo for preparing personalized WhatsApp catalogue and price messages.

## Features

- Save customer name, WhatsApp number, interested product, price, catalogue link, and notes.
- Record marketing opt-in; message launch is disabled unless opt-in is checked.
- Preview/edit the message, then open WhatsApp for manual review and sending.
- Search and delete saved customer records.
- Customer records are stored in the current browser with localStorage.

## Run

Open `index.html` in a browser, or enable GitHub Pages for this repository using the `main` branch and root folder.

## Important

This demo does not send messages automatically and does not connect to the WhatsApp Business Platform. WhatsApp opens with a prefilled draft; the user must review and send it. Use only for customers who explicitly opted in, record how and when they opted in, and honour opt-out requests. For automated business-initiated messages, use the official WhatsApp Business Platform and approved message templates.

Customer data remains in that browser/device only. It is not synced across users or devices.
